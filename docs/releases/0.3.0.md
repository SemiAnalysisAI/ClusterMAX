# ClusterMAX 0.3.0

This release adds passive kernel security checks and new audit checks,
and improves audit evidence.
It does not run exploits, change host security settings, or patch a cluster.

## Security checks

- **PwnEscape:** Add a running-kernel check for CVE-2026-99999 across the
  standalone, Slurm, and Kubernetes collectors. Hidden physical hosts and
  distribution backports require provider or vendor evidence.
- **Bad Epoll:** Add CVE-2026-46242 package checks for supported Ubuntu
  generic and NVIDIA kernel families. Keep running-kernel evidence separate
  from newer installed kernels that require a reboot.
- **Ubuntu 26.04:** Grade Bad Epoll and Fragnesia on the Ubuntu 26.04 GA 7.0
  generic kernel against its own fixed packages, instead of reporting them as
  unverified.
- **Evidence handling:** Preserve uncertainty for unreadable livepatch state,
  unsupported firmware trains, incomplete DPU isolation evidence, and failed
  BMC commands.

## Collection and reporting

- **Kubernetes:** Select Ready, schedulable workers from the primary GPU
  profile. A secondary pool cannot supply facts for that profile.
- **Host software:** Improve loaded NVIDIA driver detection, GPU Operator
  host-root discovery, and CUDA Toolkit evidence from active GPU workloads.
- **Minimum tables:** Reject unusable caches and retain shipped kernel
  mappings when the remote table lacks required release mappings.
- **Slurm workers:** Stream check source to compute workers, so an audit no
  longer needs a shared checkout. NVIDIA-only probes stay on NVIDIA nodes in
  mixed-vendor clusters.

## New audit checks

- **Tenant GPU pods:** Check memlock, shared memory, RDMA, and GDRCopy defaults
  and admission for ordinary and tuned tenant pods. Test pods are created only
  in the full and orchestration profiles.

## Upgrade notes

- New checks can add warnings to old audit files because those files lack the
  new evidence. Rerun the audit to collect it.
- A passing sampled-worker check does not certify a hidden hypervisor or the
  whole fleet. Provider attestations remain separate evidence.
- Backport and livepatch decisions require evidence for the exact CVE and
  running build. A higher package number alone does not establish a fix.

Install this version with `pip install --upgrade clustermax==0.3.0`.
Use `cmax audit security --show` to inspect the security check inventory.
